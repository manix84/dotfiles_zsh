# Privacy

## Summary

This project does not include analytics, telemetry, advertising, or tracking
code. The project maintainer does not receive data when you run the installer.

## Local information

The installer writes a timestamped setup log to the home directory of the user
who runs it. That log remains on the device unless the user chooses to share or
delete it. Shell configuration, backups, themes, and plugins are also stored in
that user's home directory.

Review logs before sharing them publicly. Remove usernames, hostnames, network
addresses, file paths, tokens, and any other information you consider private.

## Third-party services

The installer downloads software and scripts from third-party services,
including GitHub and the package repositories configured on the device. Those
services may receive standard connection information such as an IP address and
user agent, and operate under their own privacy policies.

Before running the installer, you can review [the setup script](auto-install/setup.sh)
and the third-party projects it installs. Running the installer means those
downloads are made directly from your device.

## Information shared through GitHub

Information submitted in issues, pull requests, discussions, or other GitHub
features is processed by GitHub and may be public. Do not include credentials or
other sensitive information. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
for details about GitHub's handling of that information.
